# 星忆 · 下一阶段开发计划（Web P0 收敛）

## Report

（交付实现后填写）

## [S1] Problem

现有仓库是「宿星」P1 可玩原型：写实银河 + 七步存星 + 星钥 + 本地存储。  
《星忆产品设计方案》（docx v1.0）重新定义了产品名、P0 功能清单与视觉/音效原则，并推荐 UE5。  
当前问题：

1. **产品源不一致**：代码/文档仍是宿星，方案以「星忆」为准。  
2. **P0 缺口大**：F01 创世开场、F03 悬停混合反馈、F05 恒星内部、F06 音景、F07 加密存储均未完成。  
3. **技术栈需锁定**：继续 Electron + Three.js，在 Web 上交付可感知的 P0 子集，UE5 仅作远期视觉试验。  
4. **本阶段不写业务代码**，只产出可执行的下一阶段开发计划，避免继续在视觉/文案上发散。

## [S2] Design

### 2.2 现状映射（代码 → 星忆 P0）

| 星忆 P0 | 现有 | 差距 |
|---------|------|------|
| F01 创世开场 | 简短引语黑屏 ~3s | 缺大爆炸星尘、沉淀星云、首次凝星引导闭环 |
| F02 宇宙漫游 | OrbitControls 旋转缩放 | 缺「自由飞行」WASD/速度感；可保留轨道为默认 |
| F03 悬停反馈 | 细环 + 星名一行 | 缺光晕呼吸、一句记忆预览、引力牵引、悬停音 |
| F04 记忆创造 | 七步仪式 + 凝星粒子 | 缺「星云气体汇聚→凝结」观感；七步可映射书写/选色/命名 |
| F05 记忆空间 | 二维星内态文字星尘 | 缺镜头穿越光晕、3D 玻璃碎片漫游 |

| F07 本地存储 | JSON schema 2 | 缺加密、导出星钥包；结构可用 |
| F08–F11 / F12–F16 | 部分（连线/情绪色） | 非本迭代必做 |

### 2.3 下一迭代范围（建议实现顺序，不在本阶段编码）

**里程碑 M1 — 仪式与开场（优先）**

1. **T1 产品壳对齐**  
   - 标题/README/默认窗口名 → 星忆  
   - 开场文案与 docx §4.1 对齐  
   - 验收：启动后首屏与文档文案一致；旧「宿星」仅保留在 CHANGELOG/迁移说明  

2. **T2 F01 创世开场**  
   - 状态：`blackout → boom → settle → quote → first-star-hint`  
   - 纯 3D，无表单 UI；`prefers-reduced-motion` 降为淡入+文案  
   - 验收：首次启动可完整播完；二次启动可跳过或缩短；无 JS 报错  

3. **T3 F04 星云凝结观感**  
   - 在现有 `fxConverge` 上改为：周围粒子/雾向目标点汇聚→压缩→闪亮→恒星  
   - 七步状态机保留，视觉替换  
   - 验收：存星全程可完成；凝结段约 5s；结束后星可点开  

**里程碑 M2 — 路过即共鸣**

4. **T4 F03 悬停混合反馈**  
   - 光晕呼吸（scale/opacity）  
   - 半透明一句预览（`layers[0].text` 首句或时间地点占位）≤1s 淡出  
   - 轻微引力：邻近尘埃向该星偏移（可先用 shader/粒子位移近似）  
   - 验收：不点击也能「路过认出」记忆星；性能不明显掉帧  

5. **T5 F06 音景 v0**  
   - Web Audio：宇宙底噪（可关）+ 悬停泛音 + 凝结定音  
   - 无点击「哒」声；音量开关进环形菜单  
   - 验收：静音可默认/可开；与凝结动画同步  

**里程碑 M3 — 星内空间与数据**

6. **T6 F05 记忆空间（简化版）**  
   - 点击恒星：镜头推入光晕 → 内部用玻璃碎片感 Mesh（照片贴图 + 文字浮层）  
   - 不做完整体积 raymarching（记入技术债）  
   - 验收：可飞入、点碎片看完整内容、Esc/离开回到星野  

7. **T7 F07 本地加密与星钥包**  
   - 敏感字段加密或整文件加密（Electron 侧）  
   - 导出/导入「星钥包」  
   - 验收：导出后可在另一环境导入恢复；无明文密钥进仓库  

### 2.4 明确不在本计划实现（Out of Scope 见 S3，此处为排期注记）

- UE5 迁移、完整体积渲染 LOD（docx F09 完整版）  
- P2 共建：双星、幽灵光标、星尘胶囊、云同步  
- Wwise/FMOD  

### 2.5 架构契约（实现时遵守）

- 渲染入口：`src/galaxy.js`（场景/相机/粒子/FX）  
- 仪式逻辑：`src/ritual.js`（纯状态，可单测）  
- 存储：`src/store.js` + Electron IPC（`electron/main.cjs`）  
- 音频：新增 `src/audio.js`，仅 Web Audio  
- 新场景状态：`src/scenes/opening.js`（创世），与日常星野互斥切换  
- 质量档：沿用 ENGINEERING 降级思路；开场可强制 L1 粒子上限  

### 2.6 错误与降级

| 情况 | 行为 |
|------|------|
| WebGL 失败 | 2D 静帧 + 纯 DOM 仪式 |
| reduced motion | 跳过爆炸，保留文案与静止星野 |
| 音频不可用 | 仅视觉，不阻断存星 |
| 存储失败 | 文案「星光暂时抵达不了你」，草稿保留 |

### 2.7 验证边界

- 手工：开场、存星、悬停、飞入、导出导入  
- 可自动：`ritual.js` 状态迁移单测（实现期补）  
- 性能：L0/L1 桌面空闲 ≥55fps；开场不掉到 24fps 以下
